# Curvas q_i do IQA

`src/iqa.py` contém curvas discretizadas para o simulador.

Os pesos seguem a metodologia divulgada pela ANA, mas os pontos das curvas q_i são uma
aproximação operacional para o MVP. Para o artigo empírico, substitua-os pela versão oficial
adotada no estudo, registre a fonte/ano e faça análise de sensibilidade quando houver
mudança de implementação.
